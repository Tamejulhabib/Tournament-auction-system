**The Auction | Tournament & Player Auction Management System**

Developed a web-based tournament management application using PHP and MySQL to organize tournaments, manage teams, and coordinate player participation.

The system includes role-based dashboards for administrators, team owners, and players, with functionality for tournament creation, player registration, approval workflows, team management, and auction-related activities.

**Technologies:** PHP, MySQL, MySQLi, HTML, CSS.

**Project Type:** Full-Stack Web Development / Database-Driven Application
